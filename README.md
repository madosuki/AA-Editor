# AA Editor
This is Ascii Art Editor. But mentioned here Ascii Art meaning not only art of using ascii code. Here meaning is Japanese Ascii Art with multibyte characters.  
exp. やる夫.


## target font format
like css  
```css
.text {
font-family: Monapo, MSPGothic, sans-serif
font-size: 16px;
line-height: 18px
}
```


## desgine
3 pain.  
left pain is info from text item.  
central pain is text edit.  
right pain, here close button.  

## support format
.mlt  
mlt file output is only using UTF-8.
